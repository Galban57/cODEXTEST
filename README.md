# cODEXTEST

This repository now showcases a small dashboard interface built with [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter).
It features a sidebar with navigation buttons, progress indicators for courses, a schedule section, and panels for messages and goals.

## Getting started

Install the dependency and run the application:

```bash
pip install -r requirements.txt
python main.py
```

Running the script opens a window titled **Course Activity Dashboard** using a light theme with blue accents.
